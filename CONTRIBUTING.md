# Contributing to BEXChain Docs

Thanks for contributing.

## What Can Be Contributed

- Documentation improvements
- Network metadata corrections
- Integration examples (wallets, RPC/API usage)
- Clarity and consistency updates for whitepaper references

## Contribution Flow

1. Fork this repository.
2. Create a branch with a clear name, for example: `docs/update-network-endpoints`.
3. Make focused changes (one topic per pull request).
4. Open a pull request with:
   - Summary of changes
   - Why the change is needed
   - Validation details (links, curl output, screenshots, or other proof)

## Documentation Rules

- Keep endpoint examples accurate and verifiable.
- Use UTC date stamps when recording endpoint validation.
- Avoid publishing secrets, private keys, or internal-only credentials.
- Keep language clear and production-oriented.

## Security

If your finding is security-related, follow [`SECURITY.md`](./SECURITY.md) instead of opening a public issue.
